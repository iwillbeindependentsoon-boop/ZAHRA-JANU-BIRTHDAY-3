# Zahra Birthday Website 🎂🤍

A ready-to-upload, mobile-first birthday surprise website made for Zahra.

## Files

- `index.html` — website structure and birthday messages
- `style.css` — all styling and animations
- `script.js` — interactions, confetti, photo lightbox and birthday ambience
- `assets/` — Zahra's six uploaded photos

## How to use

1. Keep the folder structure exactly as it is.
2. Open `index.html` on your phone/computer to preview it.
3. To change a photo, replace a file in `assets/` while keeping the same filename.
4. To change the birthday message, edit the text inside `index.html`.
5. The "Birthday Ambience" button uses a tiny synthesized melody, so no music file is required.
6. If you want a real song, you can later add your own `birthday-song.mp3` and replace the button/audio logic in `script.js`.

## Free GitHub Pages upload

Create a public GitHub repository, upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder, then enable GitHub Pages from the repository's Settings → Pages.

The site is static, so it does not need a server or database.
